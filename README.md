# Mêlée Island · L’hora del sabre

[**Juga a GitHub Pages**](https://skirep.github.io/melee-island/)

Aventura de fans en català ambientada a Mêlée Island. Travessa el moll i la vila, recupera la clau del capità i torna a encendre el far. El món combina geometria voxel en WebGL i personatges 2D pixel art amb animacions per fotogrames. Hi ha vuit adversaris i set veïns amb diàlegs.

| Control | Acció |
| --- | --- |
| WASD | Caminar |
| Ratolí o fletxes esquerra i dreta | Mirar o girar |
| Majúscules | Córrer |
| Espai | Saltar |
| Clic esquerre o F | Atacar |
| Clic dret o Q | Blocar |
| E | Parlar, recollir la clau o obrir el far |
| Esc | Pausa |

Obre `index.html` en un navegador d’escriptori amb WebGL o serveix l’arrel amb `python -m http.server 8000`. El joc funciona sense compilació ni dependències de tercers. GitHub Pages publica l’arrel de `main`.

Projecte de fans de Dejoco Arts. Mêlée Island pertany a l’univers de Monkey Island. L’art i el codi del joc s’han creat per a aquest projecte.
